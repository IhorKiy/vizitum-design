# Поточний стан макету

Головний оглядовий файл: **`Екрани проекту.dc.html`** — вбудовує (dc-import) усі екрани проєкту з підписами, згруповані по секціях (нумерація — за розташуванням, не хронологічна):

1. **Перший вхід / онбординг** — логін, помилка пароля, доступ до робочого простору; онбординг-вітання (3 кроки: привітання, модель роботи, офлайн); онбординг-дозволи (мікрофон+камера).
2. **Головна / Задачі** — звичайний стан, порожньо, свайп-дії, кілька непрочитаних оголошень, список задач, штори перегляду/редагування задачі.
3. **Візит** — старт, активний, нотатка, контакти (порожньо/заповнено/додавання), потенціал, асортимент, історія точки, деталі минулого візиту, скасування з причиною.
4. **Звіт про візит** — базова форма, кожен розгорнутий блок (полиця, проблема, нотатки, наступні кроки, фотозвіт, прев'ю фото), лайк/дізлайк з причиною, помилка валідації, і повна голосова підсистема (окремий еталонний файл `Голосовий звіт - всі стани.dc.html` — 10 пронумерованих сценаріїв: запис, ліміт, офлайн, переривання дзвінком, зависла обробка, транскрипт без полів, заповнено з голосу + прослуховування, мікрофон заблоковано, збереження без обробленого запису).
5. **Меню** — бургер-меню, оголошення (з фільтром категорій), маршрути (список/багато/порожньо/редагування/видалення/створення/призначення на день, разове додавання точки на день), точки, товари (з категоріями), планування (тижневе спрощене зі шторами «Місяць» і «Копіювати тиждень/місяць»), довідка, обліковий запис, зміна пароля.
6. **Стани й помилки** — порожні стани (задачі/історія/точки/оголошення), скелетон завантаження, підтвердження видалень.
7. **Історія** — список візитів, деталі візиту.

## Відкриті/незавершені моменти
