# Vizitum — редизайн мобільного застосунку для торгового представника

## Опис
Vizitum — застосунок для торгового представника (медична техніка): планування маршрутів, візити до точок продажу, звіти про візит (у т.ч. голосові). Цей проєкт — редизайн існуючого продукту, що вже в розробці/продакшені.

## Аудиторія
Торгові представники, які працюють у полі: заходять у мережеві та одиничні точки (аптеки, клініки), фіксують асортимент, потенціал, проблеми, звітують голосом або вручну.

## Цілі редизайну
- Спростити планування (тижневе/місячне) і додавання маршрутів/точок на день.
- Зробити голосовий звіт головним способом заповнення (з ручним запасним варіантом).
- Прибрати надлишкові елементи (лічильники, дублюючі заголовки), уніфікувати картки та шапки екранів.
- Підготувати повний набір станів (порожні, помилки, офлайн) для передачі в розробку.

## Статус
Активна фаза дизайну. Основні флоу промальовані: вхід/онбординг, головна/задачі, візит, звіт (включно з голосовим підсистемою — 10+ сценаріїв), планування, маршрути/точки/товари, меню, історія. Хендофф-пакет для Claude Code вже сформований (`design_handoff_vizitum_redesign/`).
